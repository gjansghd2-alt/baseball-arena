# Baseball Arena · 숫자 야구

초대 링크로 즐기는 한국어 실시간 숫자 야구입니다.

- 공통 정답 모드: 2–4명이 서버가 만든 같은 숫자를 추리합니다.
- 비밀 숫자 대결: 정확히 2명이 각자 숫자를 확정하고 번갈아 상대 숫자를 추리합니다. 먼저 상대 숫자를 맞히면 승리합니다. 상대 비밀 숫자는 종료 전 전송하지 않습니다.
- 비밀 숫자 대결은 둘 다 준비한 뒤 시작하며 재경기마다 새 숫자를 설정합니다.

- 방장이 4/5/6자리 선택. 중복 숫자와 첫 자리 0은 사용하지 않습니다.
- 입장 순서의 턴제, 시간제한 없음, 수동 차례 넘기기.
- 모든 추측과 스트라이크/볼 판정 공개. 정답은 서버에만 보관하고 종료 시 공개.
- 최초 입장자가 방장. 방장 연결 해제 시 접속 중인 다음 참가자에게 이전.
- 공통 정답 모드는 연결이 끊긴 참가자를 건너뛰고, 1대1 모드는 차례를 유지합니다. 같은 기기·브라우저에서 같은 링크를 열면 자동 복귀합니다. 참가자 인증 정보는 브라우저에 저장됩니다.
- 대기/경기/종료 후 실시간 채팅, 같은 멤버로 재경기.
- 모바일 대응 야구장 전광판 UI.

## 실행

Node.js 20 이상에서 `npm ci`, `npm start`. 기본 포트 3000, `PORT` 환경변수 지원.
검사: `npm test`. 멀티플레이 통합 검사: 서버 실행 후 `node multiplayer-check.mjs`.

Render: Node web service, 무료 플랜, build `npm ci`, start `npm start`.
메모리에 방을 보관하므로 서버 재시작/배포 시 방과 기록이 초기화됩니다. 무료 인스턴스가 휴면 중이면 첫 요청이 지연될 수 있습니다.
